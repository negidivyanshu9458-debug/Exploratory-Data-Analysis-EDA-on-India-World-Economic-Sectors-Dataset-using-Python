# 📊 Exploratory Data Analysis (EDA) on India & World Economic Sectors Dataset using Python

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on the **India & World Economic Sectors Dataset** using Python.
The main objective is to clean the dataset, analyze economic indicators, create meaningful visualizations, and generate business insights.

---

# 📖 Project Workflow

## Step 1: Import Libraries

Imported the required Python libraries:

* NumPy
* Pandas
* Matplotlib
* Seaborn

These libraries were used for data manipulation, statistical analysis, and visualization.

---

## Step 2: Load the Dataset

* Loaded the CSV file into Pandas DataFrame.
* Displayed the first and last records.
* Checked dataset shape, columns, data types, and general information.

---

## Step 3: Dataset Inspection

Performed initial data exploration by:

* Viewing sample records
* Checking column names
* Understanding data types
* Identifying missing values
* Checking duplicate records

---

## Step 4: Data Cleaning

Improved data quality by:

* Removing duplicate records
* Handling missing values
* Converting Employment (%) into numeric format
* Converting Growth Rate (%) into numeric format
* Verifying updated data types

This ensured that the dataset was ready for analysis.

---

## Step 5: Statistical Analysis

Calculated important statistical measures such as:

* Mean GDP
* Median GDP
* Maximum GDP
* Minimum GDP
* Standard Deviation

These statistics helped understand the overall distribution of the data.

---

## Step 6: Exploratory Data Analysis (EDA)

Performed detailed analysis including:

### Country-wise Analysis

* Total GDP by Country
* Average GDP by Country
* Average Employment Rate
* Average Growth Rate

### Sector-wise Analysis

* Total GDP by Sector
* Average Employment
* Average Growth Rate

### Year-wise Analysis

* GDP Trend over Years

### Combined Analysis

* Country vs Sector Pivot Table
* Crosstab Analysis

---

## Step 7: Data Visualization

Created multiple visualizations to better understand the data:

* Bar Chart
* Pie Chart
* Histogram
* Histogram with KDE
* Box Plot
* Scatter Plot
* Line Plot
* Count Plot
* Heatmap
* Pair Plot
* Violin Plot

These visualizations helped identify trends, relationships, distributions, and outliers.

## Step 8: Advanced Analysis

Performed advanced EDA including:

* Top 5 Countries by GDP
* Bottom 5 Countries by GDP

* Lowest Growth Sector

* Country with Minimum Employment
* GDP Trend Analysis

## Step 9: Business Insights

Generated business insights based on the analysis, including:

* Highest GDP contributing country
* Highest performing sector
* Employment trends
* GDP growth patterns
* Relationship between Employment and GDP
* Sector-wise economic performance
* Correlation between numerical variables
* Data quality improvements

## Step 10: Final Conclusion

The project successfully demonstrated the complete EDA process using Python.
